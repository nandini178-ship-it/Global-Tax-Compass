# Global Tax Compass

Live at: **globaltaxcompass.com**

A single-page website for checking cross-border tax residency (DTAA tie-breaker rules), tax rates, and filing guidance across 103+ countries.

## What's in this repo
- `index.html` — the entire website (HTML, CSS, and JavaScript in one file). No build step, no dependencies, no server required.

## Hosting
This site is a static file and can be hosted for free on [Vercel](https://vercel.com). See the deployment guide provided separately for step-by-step instructions, including how to connect the `globaltaxcompass.com` domain through [Cloudflare](https://cloudflare.com).
